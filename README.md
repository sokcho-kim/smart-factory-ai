# smart-factory-ai

AI 기반 스마트 공장 운영 플랫폼 MVP

## 대회 정보

- **대회**: 차세대융합기술연구원 메이커스페이스 해커톤 (운영: 데이콘)
- **주제**: AI를 활용한 스마트 공장 운영 시스템 (플랫폼) MVP 개발
- **일정**
  - 온라인 예선: MVP 기획서 제출
  - 오프라인 본선: 2026-05-22 (목) 09:30~17:30, 차세대융합기술연구원 A동 105호

## 디렉토리 구조

```
smart-factory-ai/
├── docs/
│   ├── proposal/        # 예선 기획서 (MVP 구조, AI 전략, 아키텍처)
│   ├── research/        # 사전 조사 (도메인, 데이터셋, 선행 사례)
│   └── architecture/    # 시스템 아키텍처 설계 (다이어그램, ERD)
├── data/
│   ├── raw/             # 원본 데이터 (센서, MES, 설비 로그)
│   ├── processed/       # 전처리 완료 데이터
│   └── sample/          # 시연용 샘플 데이터
├── src/
│   ├── platform/        # 플랫폼 (대시보드, API, 웹)
│   ├── ai/              # AI 모델 (학습, 추론, 파이프라인)
│   └── utils/           # 공통 유틸리티
├── notebooks/           # EDA, 모델 실험, 프로토타이핑
└── output/              # 결과물 (리포트, 시연 캡처, 발표 자료)
```

## 세부 주제 후보

| 주제 | 핵심 AI | 난이도 | 시연 임팩트 |
|------|---------|--------|------------|
| 설비 고장 예지 + 유지보수 | 시계열 이상탐지, 잔여수명(RUL) 예측 | 중 | 높음 |
| 품질 이상 예측 + 불량률 개선 | 분류/회귀, 공정 파라미터 최적화 | 중 | 높음 |
| 생산 계획 최적화 | 스케줄링, 수요 예측 | 높음 | 중 |
| 통합 대시보드 + 운영 관리 | 멀티 모델 통합, 실시간 모니터링 | 높음 | 매우 높음 |

## 기술 스택 (예정)

- **AI/ML**: Python, scikit-learn, PyTorch/TensorFlow, Prophet
- **Platform**: Streamlit / Dash / Next.js
- **Data**: Pandas, SQL
- **Infra**: Docker (본선 시연용)
