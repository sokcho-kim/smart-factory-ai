# 시나리오 E: AI 비전 검사 + 불량 원인 추적 플랫폼

## 컨셉

공장이 **돈 주고라도 사고 싶은 것** = 불량률 감소.
중소 제조업의 품질 검사는 아직도 사람 눈에 의존하는 곳이 대부분.
AI 비전 검사로 불량을 자동 탐지하고, **"왜 불량이 났는지"까지 추적**하는 것이 차별화.

## 핵심 흐름

```
라인 카메라 → AI가 불량 탐지 (YOLO + Anomaly Detection)
  → 불량 유형 분류 (스크래치/크랙/이물/변형)
  → 불량 발생 시점의 공정 파라미터 조회 (온도/압력/속도)
  → 패턴 분석으로 원인 추적 ("온도 85°C 초과 시 크랙 발생률 3배")
  → 조치 가이드 제공 ("금형 온도를 80°C 이하로 조정 권장")
```

## 제품 도면(CAD) 없이 가능한 이유

| 불량 유형 | 도면 필요? | MVP 대상 |
|----------|-----------|---------|
| 외관 불량 (스크래치, 크랙, 이물, 기포) | X — 양품 학습 후 이탈 탐지 | **O (MVP 핵심)** |
| 치수 불량 (크기, 형상 오차) | O — CAD 스펙 대비 측정 필요 | X (Phase 2) |
| 조립 불량 (부품 누락, 오삽입) | △ — 기준 이미지 필요 | X (Phase 3) |

**MVP는 외관 불량(표면 결함) 탐지에 집중.**
양품 이미지만 있으면 학습 가능 (Anomaly Detection 방식).

## 데이터셋

| 데이터셋 | 내용 | 크기 | 활용 |
|----------|------|------|------|
| MVTec AD | 15종 산업 제품 외관 결함 (5,354장) | ~5GB | 이상 탐지 벤치마크, 양품/불량 쌍 |
| Kaggle Casting Defect | 주조 제품 불량 이미지 (7,348장) | ~500MB | 이진 분류 (양품/불량) |
| SECOM | 반도체 공정 센서 590개 + 불량 라벨 | ~3MB | 공정 파라미터 ↔ 불량 연결 |
| NEU Surface Defect | 열연 강판 표면 결함 6종 (1,800장) | ~30MB | 결함 유형 분류 |
| Kaggle Steel Defect | 철강 표면 결함 세그멘테이션 | ~2GB | 결함 위치 특정 |

### 추천 조합
- **비전 모델 학습**: MVTec AD (다품종, 이상 탐지) + Casting Defect (이진 분류)
- **원인 추적 연결**: SECOM (센서 데이터 ↔ 불량 라벨)

## 역할 분담

### 원정환 (Vision & Detection Engine)
- YOLO 기반 결함 탐지 모델 학습 (Casting/Steel/NEU 데이터)
- Anomaly Detection 모델 구현 (MVTec AD 기반, PatchCore 또는 STFPM)
- 라인 카메라 시뮬레이션 (이미지 시퀀스 재생)
- Streamlit 검사 대시보드 + Docker 시연 환경

### 소지민 (Root Cause & Intelligence)
- 공정 파라미터 ↔ 불량 상관 분석 파이프라인 (SECOM 데이터 기반)
- 불량 유형별 원인 추적 로직 (Feature Importance, SHAP)
- 조치 가이드 RAG (불량 유형 → 원인 → 조치 방법 지식 베이스)
- 불량 이력 DB + 통계 리포트 생성

## 기술 스택

| 영역 | 기술 |
|------|------|
| 결함 탐지 | YOLO v11 (결함 위치), PatchCore (이상 탐지) |
| 원인 분석 | scikit-learn (상관 분석), SHAP (설명 가능 AI) |
| 조치 가이드 | LangChain + Qdrant (RAG 기반 가이드 검색) |
| Backend | FastAPI, PostgreSQL |
| Frontend | Streamlit, Plotly |
| Infra | Docker Compose |

## 시연 시나리오

```
1. 라인 카메라에서 제품 이미지 수집 (시뮬레이션)
   → 대시보드에 실시간 제품 이미지 스트림

2. AI가 불량 탐지
   → "Lot #2847 — 크랙 검출 (신뢰도 94.2%)"
   → 결함 위치 바운딩 박스 + 히트맵 표시

3. 원인 추적 (자동)
   → "최근 30분 크랙 발생 3건, 공정 조건 분석 결과:"
   → "금형 온도 87°C (정상 범위 70~80°C) — 상관계수 0.73"
   → "사출 압력 정상 범위 내"

4. 조치 가이드 (RAG)
   → "크랙 발생 시 권장 조치: 금형 온도 80°C 이하로 조정"
   → "참고: 유사 사례 — 2024년 3월 동일 라인에서 동일 패턴 발생"

5. 불량 통계 대시보드
   → 시간대별/유형별/라인별 불량률 추이
   → "오늘 불량률 2.3% (전주 대비 -0.8%)"
```

## 왜 수상 가능성이 높은가

1. **공장 니즈 직결**: 불량률 = 돈. 심사위원이 "이거 현장에 바로 넣겠다" 반응
2. **데이터 풍부**: 공개 데이터셋으로 실제 학습/시연 가능
3. **차별화**: 단순 불량 탐지가 아닌 "원인 추적 + 조치 가이드"까지
4. **팀 시너지**: 정환 CV + 지민 데이터/RAG가 자연스럽게 결합
5. **확장성 스토리**: 외관 → 치수 → 조립 → SaaS (투자 가치)
