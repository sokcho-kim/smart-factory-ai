## 시나리오 A. 설비 고장 예지 + 유지보수 관리 (Claude 제안)

### 개요
센서 데이터 기반으로 설비 고장을 예측하고, 잔여수명(RUL) 추정 + 정비 알림 대시보드 제공.

### 핵심 AI
- 시계열 이상 탐지 (Isolation Forest, LSTM Autoencoder)
- 잔여수명(RUL) 예측 (Regression, CNN-LSTM)

### 데이터셋 후보
| 데이터셋 | 내용 | 크기 |
|----------|------|------|
| NASA C-MAPSS | 터보팬 엔진 센서 21개 × 수명 전체 | ~26MB |
| Microsoft Azure PdM | 텔레메트리+에러+정비이력+고장 | ~400MB |
| SECOM | 반도체 공정 센서 590개 | ~3MB |
| Kaggle Machine PdM | 센서 6개 + 고장유형 5가지 | ~10MB |

### 강점
- 공개 데이터 풍부, 파이프라인 단순
- "고장 30분 전 알림 → 정비비 30% 절감" 직관적 스토리
- 하루 MVP 구현 가능, 시연 임팩트 높음

### 약점
- 상대적으로 흔한 주제

## 시나리오 B. 유령 도면 복원 및 안전 관제 — 공간 지능형 (Gemini 제안, 지민 선호)

### 개요
죽어있는 도면을 실시간 현장 데이터(사진/센서)와 대조하여 업데이트하고 리스크를 시뮬레이션.

### 핵심 AI
- IDP (Intelligent Document Processing): 도면 PDF → 정형 데이터 추출
- Object Detection: 현장 사진/영상에서 설비/장애물 탐지
- Image Alignment: 도면과 현장의 정합성 계산
- Graph-RAG: 산업안전법 규정 ↔ 도면 객체 관계 구축

### 역할 분담
- **지민**: Graph-RAG 설계, IDP 엔진, 안전 시뮬레이션 로직
- **정환**: CV 모델 (Object Detection, Image Alignment), 데이터 파이프라인, UI 대시보드

### 강점
- 독창성 매우 높음
- 배터리 공장 사고 등 사회적 이슈와 직결
- 포트폴리오 가치 최상
- 두 AI 엔지니어 시너지 극대화

### 약점
- 도면 파싱 + 이미지 매칭 구현 난이도 높음
- 하루 본선에서 완성도 리스크

### 협업 인터페이스
```
정환 → JSON: {"objects": [{"type": "설비A", "coords": [x,y], "status": "정상"}]}
지민 → JSON: {"violations": [{"rule": "안전통로 2m 미확보", "risk": "high"}]}
```

## 시나리오 C. 도면 기반 설비 예지보전 — A+B 융합 (Gemini 제안)

### 개요
NASA/Azure 데이터로 고장을 예측하되, 그 위치를 도면 위에 시각화하고 안전 수칙 가이드.

### 핵심 AI
- 시계열 고장 예측 (시나리오 A)
- 도면 시각화 + 안전 수칙 매칭 (시나리오 B 경량화)

### 강점
- 구현 안정성 높음 (기존 데이터셋 활용)
- 심사위원이 이해하기 쉬운 비즈니스 성과
- A의 안정성 + B의 차별성

### 약점
- 도면 연동 부분이 어중간해질 수 있음

## 시나리오 D. 제조-물류 통합 지식 그래프 — 대화형 BI (Gemini 제안)

### 개요
ERP, MES 등 흩어진 DB를 지식 그래프로 통합, 자연어로 복합 통계 추출.

### 핵심 AI

### 강점

- 비즈니스 확장성 좋음

### 약점
