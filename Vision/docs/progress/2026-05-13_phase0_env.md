## 실행 내용

### 1. 가상환경 생성
```bash
cd c:/Solo/smart-factory-ai/Vision
python -m venv .venv
.venv/Scripts/python.exe -m pip install --upgrade pip   # 26.1.1
```

### 2. PyTorch CUDA 12.4 설치
Python 3.13.1 환경에서 cu121 wheel은 없고 cu124가 제공됨.
```bash
.venv/Scripts/python.exe -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124
```
설치 결과: `torch 2.6.0+cu124`, `torchvision 0.21.0+cu124`

### 3. CUDA 확인
```python
import torch
torch.__version__         # 2.6.0+cu124
torch.cuda.is_available() # True
torch.cuda.get_device_name(0)  # NVIDIA GeForce RTX 3060 Ti
```
→ **GPU 학습 환경 정상**.

### 4. Ultralytics + 부가 패키지
```bash
.venv/Scripts/python.exe -m pip install ultralytics opencv-python pandas matplotlib seaborn scikit-learn tqdm pyyaml kagglehub onnx onnxruntime
```
설치된 주요 버전:
- ultralytics 8.4.51
- opencv-python 4.13.0.92
- onnxruntime 1.26.0
- kagglehub 1.0.1 (데이터셋 다운로드용)

### 5. Smoke test
```python
from ultralytics import YOLO
m = YOLO('yolov8n-cls.pt')   # 5.3MB 다운로드 정상
```
→ **Ultralytics 학습/추론 파이프라인 동작 확인**.
