## 목표
- NEU 6클래스 분류 학습 (crazing, inclusion, patches, pitted_surface, rolled-in_scale, scratches)
- 목표: val top-1 90%+, per-class precision 85%+
- 최대 3회 시도, 최고 결과 채택
- **추가 평가 축: 증강된 val에서의 견고성** — 1차에서 깨끗한 val 100%지만 실측 변동성에 약하면 의미 없음

## 모델 선택 근거
- **YOLO v8n-cls** — Casting과 동일 스택 통일 → FastAPI 추론 파이프라인 단순화
- NEU는 텍스처 분류 — backbone의 저주파/고주파 필터가 핵심 → pretrained가 거의 그대로 통함
- 1.4M params, 3.3 GFLOPs — 추론 시 CPU에서도 빠름 (본선 환경 헷지)

## 시도 설계

**3회 시도 모두 같은 목적이지만 다른 가설을 검증**:

| 시도 | 가설 | 핵심 차이 |
|------|------|----------|
| 1 | "clean baseline으로 천장 어디까지 가는지" | imgsz=224, 약한 augmentation |
| 2 | "텍스처 디테일 + augmentation 강화하면 real-world 견고성 ↑" | imgsz=320, mixup=0.15, degrees=25°, hsv_v=0.5, erasing=0.4 |
| 3 | "label_smoothing 0.1로 confidence 보정 + 더 큰 augmentation" | + label_smoothing=0.1, mixup=0.2, degrees=30° |

## 평가 방식 — clean acc만으로는 부족

NEU는 academic clean dataset이라 1차 시도부터 천장 가능성 있음. **현장에 배포 가능한 모델**이려면 변동성에 견고해야 함.

추가 평가 축 — `robustness probe`:
- `clean`: 변형 없음
- `mild`: rotation ±10°, brightness 0.8~1.2
- `medium`: rotation ±25°, brightness 0.6~1.4, contrast 0.7~1.3, GaussianBlur 0~1.5
- `strong`: rotation ±45°, brightness 0.4~1.6, contrast 0.5~1.5, blur 0~3, JPEG quality 30~70

## 결과

### 1차 시도 — `attempt1_baseline`

설정: imgsz=224, epochs=40, lr0=1e-3, wd=5e-4, mild aug (fliplr, flipud, degrees=10, erasing=0.2)

```
val top-1: 1.0000  (val 360장, per-class 60/60 모두 정확)
clean acc:  1.0000
mild   acc: 1.0000
medium acc: 0.7056  ← 무너짐
strong acc: 0.3056  ← 처참
```

**문제 발견**: clean 100%지만 medium augmentation에서 70.6% — 즉 **모델이 데이터 텍스처를 매우 좁게 외움**. 회전·블러·밝기 조금만 바뀌어도 무너진다. 시연 환경(조명, 카메라 각도)에 그대로 노출되면 위험.

→ 1차 정확도가 만점이지만 **재학습 필수**.

### 2차 시도 — `attempt2_strong_aug`

설정: imgsz=320, epochs=60, lr0=1e-3, wd=5e-4
- mixup=0.15 (클래스 경계 모호 케이스 부드럽게 학습)
- degrees=25° (학습 단계에서 회전 다양성)
- hsv_v=0.5 (밝기 변동)
- erasing=0.4 (결함 일부 가려져도 분류)
- translate=0.2, scale=0.7

```
clean acc:  1.0000
mild   acc: 1.0000
medium acc: 0.7639  (+6.4%p vs attempt 1)
strong acc: 0.4583  (+14.7%p vs attempt 1)
```

→ **clean 100%를 유지하면서도 견고성 개선 확실**.

### 3차 시도 — `attempt3_strong_aug_smooth`

설정: imgsz=320, epochs=80, lr0=5e-4, wd=1e-3
- mixup=0.2, degrees=30°, hsv_v=0.5, erasing=0.4
- **+ label_smoothing=0.1**

```
clean acc:  1.0000
mild   acc: 1.0000
medium acc: 0.6500  ← attempt 2보다 나빠짐
strong acc: 0.3556  ← attempt 2보다 나빠짐
```

→ label_smoothing이 오히려 해. NEU 같은 텍스처 분류는 클래스 경계가 비교적 명확해서 smoothing이 학습 시그널을 흐리게 만든 것으로 추정. 더 큰 augmentation(degrees=30°)은 좋은 방향이지만 smoothing의 부작용이 더 컸음.

## 학습된 결과의 한계 (정직 검토)

NEU 데이터는 깨끗한 academic benchmark이고 1800장 중 1440이 학습에 들어간다. **실제 강판 라인 영상이 들어오면 이 모델은 도메인 갭 때문에 성능이 떨어진다**. 본선 시연은 "본 데이터셋 기준 성능"으로 발표하면 됨.

추가 robust성을 위해서는 (시간 되면):
- MVTec AD 양품 100장+ 추가하여 fine-tune
- 실 라인 영상 일부로 supervised contrastive learning
- 5/17 PatchCore와 결합하여 "분류 + 이상 탐지" 이중 안전망
